## 旧版の記録

ブラウザだけで遊べる戦闘プロトタイプ。対戦中の主要情報と手札は1画面内に固定し、長い情報・ログ・デバッグは右上のボタンから開けます。スマートフォンは横画面を使用してください。`index.html` を開くか、`new_game` ディレクトリで `python3 -m http.server 8000` を実行して `http://localhost:8000/` を開きます。外部サーバーやデータベースは不要です。

## 遊び方

1. 「速攻 / 進軍」または「防衛 / 射撃」を選びます。CPUは反対のデッキです。先攻はランダムです。
2. 初手4枚を見て、交換したいカードを選びます。
3. PCでは手札にカーソルを合わせるとカードが拡大します。クリックで使用対象を選びます。スマホでは1回タップでカードが拡大し、同じカードをもう一度タップすると対象選択へ進みます。盤面の空白を押すと選択解除します。緑の模様は召喚、青は移動、赤は攻撃、金はスペルや進化の対象です。合法な対象を選ぶと即実行します。
4. EPと進化解禁ターンが揃ったら「進化」を押し、光る味方を選びます。その時点でEPを消費して進化します。進化時効果の対象も最後の対象選択で即実行します。
5. 敵COMMANDERをDOWNさせれば勝利です。

## ルール

- 7×7。最初は両軍のCOMMANDERだけ。中央拠点はターン終了時にそこにいる陣営が支配します。空白なら中立に戻ります。
- 20枚山札、初手4枚、各自軍ターン開始時1ドロー、手札上限7。山札切れはドローなし。簡易マリガンは1回。
- ENERGY初期3、以後自軍ターン開始時に+3、中央支配でさらに+1。最大8、未使用分は持ち越し。カード使用はユニット行動数を消費しません。
- 自陣2列に召喚。召喚したターンは通常行動不可。各自軍ターンで異なるユニット最大3体が行動できます。
- 全員が周囲8方向に1マス移動・隣接近接攻撃。剣士と騎士団長は前方2、槍兵は直線2も移動。弓・魔法は射程3で2ダメージ。弓は障害物とユニットを越せず、魔法は障害物を1つ越せます。隣接敵がいると遠隔攻撃できません。
- HP0はDOWN。次の自軍ターン終了時に墓地へ。救命で復帰できます。DOWN中もマスと射線を塞ぎます。
- EPは各陣営2。先攻は自軍5ターン目、後攻は自軍4ターン目から進化できます。進化はユニットごとに移動・位置交換・押し出しなどの効果を持ちます。

## Ver.0.6 対戦画面

ゲームの数値・デッキ・勝利条件はVer.0.4と同じです。手札・駒・敵を選ぶと、盤面上の候補と現在の操作を表示します。攻撃、召喚、スペル、進化は結果を確認して「実行」を押します。複数の対象があるスペルや突撃では、作用元、着地点、攻撃対象を順番に選びます。選択解除はESC、盤面の空白、または右側のボタンです。敵駒を選ぶと移動範囲と現在の射線・攻撃範囲を確認できます。

対戦画面はスクロールせず、スマホ横画面では両軍の資源を左端にまとめます。履歴、墓地、詳細、デバッグは右上から開きます。

- `test_v05_engine.html`：複数対象とダメージ予測の検証。
- `test_v05_ui.html`：手札・プレビュー・キャンセルの検証。
- `test_v05_flows.html`：入れ替え・強行突破・突撃・進化の連続操作。

Ver.0.6では画面全体を仮戦場背景とし、7×7グリッドを拡大しました。山札と墓地はカード束、相手の手札は裏向きカードで表示します。リーダー欄は将来の見た目用の仮シルエットです。対戦中のカードはコスト・役割・主要数値を優先して表示し、能力全文は詳細で確認できます。

- `test_v06_ui.html`：役割・使用不能理由・カード詳細と使用の分離。
- `test_v06_flows.html`：召喚・スペル・突撃・進化の一連の操作。

## Ver.0.9 戦闘操作

通常移動、攻撃、召喚、スペル、突撃、進化と進化時効果は最後の合法な対象を選んだ時点で即実行します。選択中はESC、盤面の右クリック、選択解除、別の対象選択で戻れます。攻撃可能な敵本体に赤い輪郭と⚔を付け、PCではホバー、スマホ横では小型表示で防御込みのダメージ・HP変化を事前に確認できます。射程内で撃てない敵には短い理由を表示します。遠隔射線、ログ、攻撃後のダメージ表示は維持します。敵脅威の斜線は「現在の攻撃範囲」であり、移動後の範囲は含みません。ゲームルール、カード、デッキ、CPUは変更していません。

- `test_v09_flows.html`：近接・遠隔、遮断、接敵、召喚、救命、入れ替え、強行突破、突撃、進化、中央占領、致死予測の操作。
- `test_v09_layout.html`：3解像度で盤面、攻撃対象、射線、予測、実ヒット判定を確認。
